# Your first stage and layout

[Guide home](README.md) · [Canvas reference](CANVAS.md) · [Sharing](SHARING.md)

## 1. Sign in

Choose **Sign in**, then **Continue with GitHub**. Authorise the app and return to Stageplot. A new account immediately becomes a **User**. You can create stages, equipment, layouts and organisations without approval.

GitHub must provide a verified email address. If you already have an older unlinked app account using that email, ask the Owner to link it explicitly so its existing work stays attached to the correct account. See [account linking](ACCOUNTS.md#existing-accounts).

Without signing in, you can start on a supplied generic stage or open a client invitation. Guest layouts support equipment placement, saving and export.

## 2. Choose a workspace

Use **Personal workspace** for your own library, or select an organisation you belong to. The organisation filter shows team stages, equipment and layouts, and uses that team's stock quantities.

Organisation owners can change the team name in organisation settings. The current name and logo appear beside layout/stage details in PDF headers. Canvas exports fit a single page at the paper size selected in the print dialog.

The main navigation contains Dashboard, Stages, Layouts, Equipment, Organisations, Public library and Public stages. App Admins and the Owner also have review/import tools.

## 3. Create or choose a stage

Choose **Create stage**, enter its name and dimensions, and optionally share it with organisations. Open the stage editor.

- Adjust the main boundary and add stage zones, curtains, labels, dimensions or backgrounds.
- Place installed equipment from the library drawer at the bottom.
- Continue editing the stage and equipment in the same canvas.
- Use **Available equipment** to choose movable equipment for clients.
- Choose **Save stage version**.

Stage measurements are metres. Equipment design measurements are centimetres. The left sidebar separates stage layers from equipment layers. Curtains default to black with 10 cm peak-to-trough waves and fixed 40 cm spacing; drag their endpoints or use the inspector to change the line, colour, thickness and opacity. A selected curtain's dotted centre line marks its collision boundary. [Stage editor details](CANVAS.md#build-a-stage).

You can also create a layout on an existing stage shared with your account or organisation, or choose a public stage.

## 4. Add your own equipment

Choose **Create equipment** from Equipment or the canvas library drawer. Give it a name, category and physical dimensions. Add shapes, vectors, text or images. Add component requirements such as a microphone in the base inspector.

Choose **Save equipment**. It stays private unless you select organisations or submit it for public review. Return to the stage/layout and restore local work if offered.

Images behave like other artwork layers. Cropping trims edges without stretching; saved images are reduced to one pixel per centimetre of their placed size. Components are enabled by default when equipment is placed. [Equipment guide](EQUIPMENT.md).

## 5. Create a layout

For your own arrangement, choose **Create layout** on the stage card. Enter a name. You own a layout created this way even when the stage belongs to someone else. Optionally share it with the stage owner.

Click equipment in the bottom drawer or drag it onto the stage. Select an item to adjust its position, whole-degree rotation, label, component checkboxes and notes, or equipment source.

Installed equipment and stage geometry are locked in layout editing. Expand the initially collapsed Stage layers to inspect the source stage. Stage authoring remains available through the stage's own Edit action when you have permission.

For a team layout, select the organisation workspace before creating it. Installed stock is counted first; automatic sourcing then uses venue stock before client supply.

## 6. Invite clients instead

From a stage you own, open **Share stage** and create a client invitation. Select your personal dashboard or an organisation you administer as the destination.

Send the same invitation to every performer or client. Each enters a name and chooses **Start my layout**. The app creates a separate organiser-owned layout referencing the stage. Clients need no account and can only arrange equipment.

Each registration receives a private edit link. Keep that link for returning to the same layout. Sharing this edit link lets people collaborate on that layout; sharing the stage invitation creates separate layouts. [Link types and permissions](SHARING.md).

## 7. Finish, review and export

Layouts autosave. **Save now** saves immediately; check that the saved indicator is clear before leaving. Add performance notes and choose **Submit for review** when ready.

The organiser can approve a layout or request changes with feedback. **Details & sharing** provides revisions, source-stage updates and link management.

- **Export PDF** prints the canvas.
- **Equipment list** shows quantities and enabled components beneath their parent equipment.
- Export the equipment list as CSV or use its in-app PDF preview.
- Organisation logos appear on team exports and organisation-issued links.

[Review, export and recovery](EXPORTS_AND_RECOVERY.md).

## 8. Keep your library organised

Use **Remove from my library** to hide a shared stage or layout from your account. Open **Removed items** to restore it. This does not alter the source item or other people's libraries.

Use **Delete layout** only for a layout you own. Deletion stops its private edit link while leaving the source stage intact.

For repeat work, maintain a source stage, create a new layout for each arrangement, and use organisations for equipment shared with your team.
